# CoinIn Google SEO Checklist

Checklist manual setelah deploy:

1. Buka Google Search Console: https://search.google.com/search-console
2. Tambahkan property tipe `Domain`: `coinin.store`.
3. Verifikasi DNS sesuai TXT record dari Google.
4. Submit sitemap:
   - `https://coinin.store/sitemap.xml`
   - `https://www.coinin.store/sitemap.xml`
5. Pakai URL Inspection dan klik `Request Indexing` untuk:
   - `https://coinin.store/`
   - `https://coinin.store/top-up-game`
   - `https://coinin.store/games`
   - `https://coinin.store/game/mobile-legends`
   - `https://coinin.store/game/free-fire`
   - `https://coinin.store/game/pubg-mobile`
   - `https://coinin.store/game/honor-of-kings`
6. Pantau query di menu Performance:
   - `coinin`
   - `coinin store`
   - `top up game`
   - `top up game online`
   - `top up mobile legends`
   - `top up free fire`
   - `top up pubg mobile`
   - `top up qris`

Catatan:
- Ranking tidak instan. Indexing bisa cepat, tapi naik ke keyword umum butuh konten, umur domain, performa, dan backlink.
- Share link CoinIn di media sosial, profil bisnis, komunitas, dan partner untuk membangun sinyal brand/backlink.
- Jangan pakai jasa backlink spam karena bisa merusak reputasi domain.
